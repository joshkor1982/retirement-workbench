What to Master, by Company

How to Use

Add each company you want to work for, then the skills, protocols, and tools you need to know there. Group them by area, like Protocols or Platform, and add a link to where you will learn each one. Click a skill's status to move it from To Learn to Learning to Mastered; one more click starts it over. Put the same skill under two companies if both want it. Generate Topics has the Advisor add what the company expects that you have not listed, reading the job posting when you paste one. Each company has its own tailored resume; mastered skills can go straight onto it.
